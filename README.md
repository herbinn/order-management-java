# Order Management System 📦

Este é um sistema desenvolvido em **Java** para console que simula o gerenciamento de pedidos de uma loja, aplicando conceitos fundamentais de Orientação a Objetos (POO), composição entre classes e manipulação de datas.

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** Java
* **IDE:** Spring Tools for Eclipse (STS) / IntelliJ IDEA
* **Controle de Versão:** Git / GitHub

## 🎯 Funcionalidades
* Cadastro de clientes com nome, e-mail e data de nascimento.
* Criação de pedidos com data e status utilizando enumerações (`Enum`).
* Adição de múltiplos produtos a um pedido.
* Cálculo automático do subtotal de cada item e do valor total do pedido.
* Exibição de um resumo completo do pedido com informações do cliente, produtos e total da compra.

## 💡 Conceitos Aplicados
* Programação Orientada a Objetos (POO)
* Encapsulamento e composição entre objetos
* Construtores, getters e setters
* Enumerações (`Enum`)
* Manipulação de datas com `Date` e `SimpleDateFormat`
* Coleções (`List` e `ArrayList`)
* Sobrescrita do método `toString()`
